# TwitchCraft — интеграция Twitch и VK Video Live с Minecraft (Fabric 26.3)

Мод для стримеров: **баллы канала, подписки, битсы, фолловы, рейды, чат-команды** на Twitch,
**чат, награды за баллы и фолловы на VK Video Live** и **донаты через DonationAlerts / DonatePay**
запускают события прямо в игре — спавн мобов, молнии, эффекты, подарки, заголовки, звуки и тосты.

> **Подробный гайд и мануал по всем функциям** (пошаговая настройка, каждое поле конфига, все команды, диагностика, FAQ) — в файле [`MANUAL.md`](MANUAL.md). Ниже — короткая справка.

> **Скачать готовый мод:** [github.com/cherdakmd/twitchcraft/releases](https://github.com/cherdakmd/twitchcraft/releases/latest) · история версий — [`CHANGELOG.md`](CHANGELOG.md) · сборка из исходников — раздел 8.

- Minecraft **26.3** (Java Edition), **Fabric Loader 0.19.5+**, **Fabric API 0.161.0+26.3**
- Клиентский мод для одиночной игры (на серверах тоже работает, если у тебя есть OP)
- Никаких ключей/секретов в коде: авторизация через официальный **Device Code Flow** Twitch
- Все действия настраиваются **в игре** (экран настроек через Mod Menu или `/twitch config`) или в одном JSON-файле
- **Подарки** за фоллов, подписку и рейд из таблиц лута, **цели** («каждые 10 фолловеров — награда») с прогрессом в оверлее
- **Донаты**: DonationAlerts (в реальном времени) и DonatePay (опрос раз в 20 с) — 10 готовых эффектов по сумме, свои пороги для каждого сервиса, цели по сумме донатов
- **Сборы средств** — полоса вверху экрана **в стиле боссбара** («Сбор на микрофон: 3 500 / 10 000 ₽»), которую заполняют донаты, битсы, подписки и баллы; эффект при закрытии
- **VK Video Live** (live.vkvideo.ru): чат, чат-команды, награды за баллы канала и фолловы работают через те же действия, что и Twitch — одновременно с ним
- **Две награды за баллы по умолчанию** — «Пакость» (случайное ☠ событие из ценника) и «Подарок» (случайное ★), по 250 баллов
- **События игры → чат**: смерти со счётчиком («смерть №7 за стрим»), **все** достижения (включая модовые), победы над боссами
  и смена измерения объявляются в чаты Twitch и VK; команды зрителей `!смерти` и `!время`
- **Клипы и метки стрима Twitch** автоматически при смерти, донате от 50 ₽ и победе над боссом; **F10** / `/twitch clip` — вручную
- **Таймеры чата**: напоминание о ценнике раз в 15 минут (и любые свои), но только когда чат живой
- **20 модулей** — любую функцию можно выключить одной кнопкой
- Чат Twitch и VK прямо в игре, ответы зрителям, оверлей, очередь, кулдауны, статистика, журнал

## 1. Установка (готовый мод)

1. Поставь Fabric для Minecraft 26.3: скачай установщик на <https://fabricmc.net/use/installer/>,
   выбери версию игры **26.3**, нажми *Install*.
2. Скачай **Fabric API** для 26.3 (файл `fabric-api-0.161.0+26.3.jar`):
   <https://modrinth.com/mod/fabric-api/versions?g=26.3>
3. Положи в папку `.minecraft/mods/` два файла:
   - `fabric-api-0.161.0+26.3.jar`
   - **[`twitchcraft-1.8.0.jar`](https://github.com/cherdakmd/twitchcraft/releases/latest)** — готовый JAR из GitHub Releases
     (там же лежит необязательный `artifact-addon-1.0.0.jar` — аддон «Артефакты»); все опубликованные версии —
     на странице **[Releases](https://github.com/cherdakmd/twitchcraft/releases)**. В папке `release/` репозитория
     лежат jar версий 1.7.0 и 1.7.1 и `ЦЕННИК.md` — текст для панели под стримом.
4. **По желанию** — [Mod Menu](https://modrinth.com/mod/modmenu/versions?g=26.3) (файл `modmenu-21.0.0.jar`) в ту же папку:
   тогда в главном меню появится кнопка **Моды**, а у TwitchCraft — кнопка **Настроить** с полным редактором.
   Без Mod Menu тот же экран открывается командой `/twitch config` из любого мира.
5. Запусти лаунчер с профилем **fabric-loader-26.3**.

> Папка `.minecraft` в Windows: `%APPDATA%\.minecraft`, в macOS: `~/Library/Application Support/minecraft`, в Linux: `~/.minecraft`.

> **Обновляешься с 1.x?** Просто замени jar. Конфиг дополнится новыми разделами сам
> (`modules`, `goals`, таблицы лута, `donations`, `fundraisers` — сбор средств, `vk` — VK Video Live, `gameEvents` / `timers` / `clips` — 1.7.0), твои награды и команды останутся.
> **После обновления на 1.7.0 сделай `/twitch logout` → `/twitch login`** — токен должен получить права на клипы и метки стрима
> (`clips:edit`, `channel:manage:broadcast`). Порт входа VK по умолчанию исправлен на `8638` (как в инструкции; в 1.6.0 в коде стоял `8632`):
> если ты создавал приложение VK с `http://localhost:8632/vk`, поменяй Redirect URI в карточке приложения или верни `vk.callbackPort: 8632`.
> После обновления на 1.6.0 дюжина наград-примеров (если ты их не менял) заменяется двумя случайными — «Пакость» и «Подарок»;
> к своим наградам эти две просто добавляются. Копия прежнего конфига — `twitchcraft.json.bak-v6`.
> После обновления на 1.5.0 таблица донатов по умолчанию (если ты её не менял) заменяется новым ценником из 51 события,
> а старый файл сохраняется рядом как `twitchcraft.json.bak-v5`. Свою таблицу мод не трогает — новый ценник можно
> загрузить командой `/twitch donations preset`.
>
> После обновления на 1.4.0 вверху экрана появится полоса «Сбор на стрим: 0 / 5 000 ₽» — это пример сбора средств;
> не нужен — `/twitch fund hide Сбор` (раздел «Сборы средств» ниже).
> Если обновляешься с 1.0.0 — один раз сделай `/twitch logout` → `/twitch login`, чтобы выдать моду новые права
> (чат, ответы, управление наградами).

## 2. Регистрация приложения в Twitch (один раз, 2 минуты)

Twitch требует, чтобы у каждой программы, которая читает события канала, был свой **Client ID**.

1. Зайди на <https://dev.twitch.tv/console/apps> под аккаунтом **dedworkshop**
   (нужна включённая двухфакторная аутентификация — Twitch требует её для разработчиков).
2. Нажми **Register Your Application** и заполни:
   - **Name:** любое, например `TwitchCraft dedworkshop`
   - **OAuth Redirect URLs:** `http://localhost`
   - **Category:** `Game Integration`
   - **Client Type:** **Public** ← обязательно! Иначе авторизация без секрета не заработает.
3. Нажми **Create**, затем **Manage** у созданного приложения и скопируй **Client ID**
   (длинная строка из букв и цифр). **Client Secret не нужен** — не создавай его.

## 3. Первый запуск

**Через экран настроек** (если поставил Mod Menu): главное меню → *Моды* → *TwitchCraft* → *Настроить* →
*Общие настройки* → вставь Client ID → *Сохранить* → кнопка **Войти в Twitch**. Код и кнопки
«Открыть twitch.tv/activate» / «Скопировать код» появятся прямо на экране — в мир заходить не обязательно.

**Через команды** — зайди в любой мир и введи в чат:

```
/twitch setup ВСТАВЬ_СЮДА_CLIENT_ID
/twitch login
```

В чате появится **ссылка** на `twitch.tv/activate` и **код из 8 символов**:

1. Кликни по ссылке (откроется браузер) — убедись, что ты вошёл как **dedworkshop**
   (владелец канала; именно его события мы будем получать).
2. Кликни по коду в чате — он скопируется. Вставь код на странице, нажми **Активировать**.
3. Подтверди права: *награды, подписки, битсы, фолловеры, чтение и отправка чата, управление наградами*.
4. Вернись в игру — через пару секунд увидишь:
   `[Twitch] Подключено к Twitch как dedworkshop — подписок: 8/8 (+чат)`

Дальше мод подключается **автоматически** при каждом входе в мир.
Токены обновляются сами, повторно логиниться не нужно.

**Награды на Twitch можно не создавать руками** — введи `/twitch rewards sync`, и мод создаст на канале
все награды из конфига (с ценой и описанием). Награды, созданные модом, он умеет **подтверждать** и
**возвращать за них баллы**, если событие не выполнилось.

## 4. Проверка без зрителей

```
/twitch test follow
/twitch test sub
/twitch test resub 12
/twitch test gift 5
/twitch test cheer 1000
/twitch test raid 50
/twitch test reward Зомби
/twitch test chat !zombie        ← имитация сообщения в чате Twitch
/twitch test goal Фолловеры      ← имитация достижения цели
/twitch rewards                  ← список наград, клик по награде = тест
/twitch replay  (или F9)         ← повторить последнее событие
```

В экране настроек у каждой награды, события, чат-команды и цели есть кнопка **Тест** (нужно быть в мире).

Тестовые события не трогают Twitch, не ставят награды на кулдаун, не попадают в статистику и **не засчитываются в цели**
(прогресс целей можно подвинуть вручную: `/twitch goals add Фолловеры 3`).

## 5. Горячие клавиши и оверлей

| Клавиша | Действие |
|---|---|
| **F8** | Пауза / продолжить. На паузе события копятся в очереди и выполняются после |
| **F7** | Показать / скрыть оверлей (статус, статистика сессии, прогресс целей, последние события) |
| **F9** | Повторить последнее событие |
| **F10** | Сделать клип стрима Twitch (и метку) прямо сейчас — ссылка придёт в чат игры и в чаты зрителей через ~15 с |

Клавиши меняются в *Настройки → Управление → TwitchCraft*. Оверлей настраивается в экране настроек
(*Общие настройки → Оверлей*) или в разделе `overlay` конфига (угол экрана, количество событий, время показа, цели).

## 5а. Экран настроек (Mod Menu / `/twitch config`)

Всё, что есть в конфиге, можно править в игре — без текстового редактора:

| Экран | Что там |
|---|---|
| **Главный** | Аккаунт и состояние подключения, код авторизации, кнопки *Войти / Выйти*, *Подключиться / Отключиться*, *Перечитать конфиг*, *Создать награды на Twitch* |
| **Модули** | 16 переключателей (см. раздел 5б). Применяются сразу; если изменился набор событий — мод сам переподключится к Twitch |
| **Общие настройки** | Client ID, автоподключение, чат, очередь и лимиты, запрещённые команды, награды (API), оверлей, цели. Кнопка *Сохранить* |
| **События Twitch** | Фоллов / подписка / ресаб / подарки / рейд / битсы: *Изменить* (редактор действия), *Тест*, *Пороги* (список «от N») |
| **Награды за баллы** | Список наград: добавить / изменить / тест / удалить. В редакторе — стоимость, описание, ввод текста, цвет |
| **Чат-команды** | То же для `!команд`: права, алиасы, кулдауны |
| **Цели** | Список целей с прогрессом, добавить / изменить / тест / удалить, сброс прогресса |
| **Сборы средств (боссбар)** | Список сборов с прогрессом, настройки полос (отступ, анимация); редактор — имя, заголовок, цель, собрано, цвет и стиль полосы, что засчитывать, эффект при закрытии |

**Редактор действия** — одно окно для награды, события, порога, чат-команды, цели и записи лута: сообщение, заголовок,
подзаголовок, текст над хотбаром, уведомление, звук (громкость / высота), ответ в чат Twitch, команды (по одной на строку),
одна случайная / шанс / сообщение при неудаче, повторы, кулдауны и **таблица лута**. Кнопка *Тест* выполняет
черновик прямо сейчас, *Сохранить* записывает в `twitchcraft.json`, *Отмена* всё отбрасывает.

Экраны не ставят игру на паузу — события Twitch продолжают выполняться, пока открыты настройки.

## 5б. Модули

Каждая функция мода — модуль. Выключенный модуль не создаёт подписок EventSub, не обрабатывает свои события
и не показывает свои элементы интерфейса. Переключать: экран *Модули*, `/twitch module <id> on|off|toggle`
или раздел `"modules"` конфига. Список — `/twitch modules`.

| id | Модуль | Что делает |
|---|---|---|
| `follows` | Фолловы | событие «новый фолловер» → действие `follow` |
| `subscriptions` | Подписки | новые подписки, продления, подарки (`subscribe`, `resub`, `giftSub` + пороги) |
| `bits` | Битсы | донаты битсами с порогами `cheer` |
| `raids` | Рейды | входящие рейды + пороги `raidTiers` |
| `channelPoints` | Баллы канала | активации наград из `rewards` |
| `twitchChat` | Чат Twitch в игре | сообщения чата в чате Minecraft |
| `chatCommands` | Чат-команды | `!zombie` и прочие `chatCommands` |
| `chatReplies` | Ответы в чат | `reply`, автоответы про кулдаун и права, `/twitch say` |
| `rewardManagement` | Управление наградами | `rewards sync`, подтверждение и возврат баллов |
| `goals` | Цели | накопительные цели и их прогресс |
| `fundraisers` | Сборы средств | полоса сбора в стиле боссбара вверху экрана (донаты / битсы / подписки / баллы) |
| `overlay` | Оверлей | F7 |
| `hotkeys` | Горячие клавиши | F7 / F8 / F9 / F10 |
| `eventLog` | Журнал событий | `logs/twitchcraft-events.log` |
| `donationAlerts` | DonationAlerts | донаты DonationAlerts в реальном времени (см. раздел 5в) |
| `donatePay` | DonatePay | донаты DonatePay (опрос API раз в 20 с) |
| `vkVideoLive` | VK Video Live | чат, команды, награды за баллы и фолловы с live.vkvideo.ru (раздел 5г) |
| `gameEvents` | События игры → чат | смерти, достижения, боссы, смена измерения → сообщение в чаты Twitch и VK; `!смерти`, `!время` (раздел 5д) |
| `chatTimers` | Таймеры чата | периодические сообщения бота (ценник раз в 15 мин, соцсети…), когда чат живой (раздел 5д) |
| `clips` | Клипы и метки Twitch | клип и метка стрима при смерти / донате от N / боссе, F10 и `/twitch clip` (раздел 5д) |

## 5в. Донаты — DonationAlerts и DonatePay

Оба сервиса работают **независимо от Twitch** (можно даже не входить в Twitch), подключаются автоматически при входе в мир
и показываются в `/twitch status`, оверлее (`DA●` / `DP●`) и на экране *Донаты* (`/twitch config` → **Донаты**).
Каждый сервис — отдельный модуль (`donationAlerts`, `donatePay`): выключил модуль — соединение закрыто, донаты не обрабатываются.

### Как это работает

Донат → мод определяет сумму **в основной валюте** (`donations.currency`, по умолчанию `RUB`) → выбирает **самый большой порог**
из таблицы `donationTiers`, не превышающий сумму → выполняет действие (сообщение, заголовок, звук, тост, команды, таблица лута — всё как у наград).
Донаты в другой валюте DonationAlerts сам пересчитывает в валюту твоего аккаунта (поле `amount_in_user_currency`); DonatePay работает в рублях.

По умолчанию в моде готовый **ценник из 51 события**: «Спасибо» за любую мелочь, **25 пакостей ☠** и **25 подарков ★**
на суммы от 30 до 5 000 ₽ (ключ = «от скольки»; всё редактируется на экране *Донаты → Общие эффекты* или в JSON).
Плохие и хорошие события чередуются: 30 ☠, 40 ★, 50 ☠, 60 ★ … — зритель сам выбирает, помочь тебе или устроить хаос.

непустая таблица сервиса используется **вместо** общей.

### DonationAlerts (в реальном времени, нужно 3 минуты)

1. Зайди на <https://www.donationalerts.com/application/clients> (под аккаунтом стримера) → **Создать приложение**.
   Название любое (например, `TwitchCraft`), **Redirect URI**: `http://localhost:8631/da` (ровно так; порт можно сменить в настройках — `donations.callbackPort`).
2. Скопируй **Client ID** (число) приложения. Секрет (Client Secret) **не нужен** — мод его не спрашивает и не хранит.
3. В игре: `/twitch donations da client <Client ID>` (или впиши его на экране *Донаты* и нажми *Сохранить*).
4. `/twitch donations da login` (или кнопка *Войти в DonationAlerts*) → откроется браузер → **Разрешить**.
   Страница сообщит «Готово!», а в игре появится «DonationAlerts: вход выполнен как …», и мод подключится сам.

Мод запрашивает права `oauth-user-show` (кто ты), `oauth-donation-subscribe` (получать донаты) и `oauth-donation-index`
(прочитать список донатов — нужно только чтобы **догнать** донаты, пришедшие за секунды обрыва связи; без этого права мод работает,
просто не догоняет). Токен хранится в `config/twitchcraft-donations.json` и действует долго; если DonationAlerts его отзовёт,
мод напишет «токен недействителен — войди заново».

Безопасность входа: ссылка содержит одноразовый параметр `state`, который сверяется при возврате, а локальный приёмник
токена отвергает запросы с чужих сайтов (`Sec-Fetch-Site: cross-site`) и принимает токен ровно один раз. Так посторонняя
страница в браузере не сможет подсунуть моду чужой аккаунт DonationAlerts. На Linux/macOS файлы с токенами
(`twitchcraft-tokens.json`, `twitchcraft-donations.json`) создаются с правами «только владелец».

> Входил в DonationAlerts в версии 1.3.0? Чтобы заработала догонка пропущенных донатов, один раз перелогинься:
> `/twitch donations da logout` → `/twitch donations da login`. Всё остальное работает и со старым токеном.

Техника: мод получает `socket_connection_token`, открывает WebSocket `centrifugo.donationalerts.com`, подписывается на канал
`$alerts:donation_<id>` и получает донаты мгновенно. Токены Centrifugo у DonationAlerts короткоживущие (около 10 минут) — мод
продлевает их заранее (команды `refresh`/`sub_refresh`), поэтому соединение не рвётся каждые 10 минут. При обрыве переподключается
сам (2, 4, 8… до 60 с) **тихо** (без спама в чат, если перерыв короче минуты), повторы одного доната отбрасываются, а после
переподключения через API проверяет, не пришло ли что-то, пока сокет был мёртв.

### DonatePay (опрос раз в 20 секунд)

1. В кабинете <https://donatepay.ru> → **Настройки → API** скопируй свой **API-ключ** (это секрет — не показывай на стриме).
2. В игре: `/twitch donations dp key <ключ>` (или поле *API-ключ* → *Применить ключ* на экране *Донаты*).
   Мод проверит ключ (покажет имя аккаунта), запомнит **последний уже существующий донат** и дальше будет забирать только новые.

Ограничение самого DonatePay: запросы к API разрешены не чаще **одного раза в 20 секунд**, поэтому эффект приходит с задержкой до 20 с
(`donations.donatePayPollSeconds`, меньше 20 поставить нельзя). Донаты со статусом `wait` (платёж ещё идёт) мод дожидается и выполняет,
когда они станут `success`; отменённые пропускает; **тестовые оповещения из кабинета** (статус `user`) выполняются как тест (без учёта в целях).

### Команды и настройки донатов

| Команда | Описание |
|---|---|
| `/twitch donations` | Статус обоих сервисов и короткая инструкция |
| `/twitch donations da client <id>` / `da login` / `da cancel` / `da logout` | DonationAlerts: сохранить Client ID, войти через браузер, отменить вход, удалить токен |
| `/twitch donations dp key <ключ>` / `dp logout` | DonatePay: сохранить и проверить ключ / удалить ключ |
| `/twitch donations connect` / `disconnect` | Подключить / отключить оба сервиса вручную (`da connect`, `dp disconnect` — по отдельности) |
| `/twitch donations prices` | Показать ценник (☠ плохие / ★ хорошие события по сумме) |
| `/twitch donations preset` | Заменить общую таблицу готовым ценником из 51 события (попросит подтверждение, старый конфиг сохранится в копии) |
| `/twitch test donation [сумма] [сообщение]` | Имитировать донат |

```jsonc
"donations": {
  "currency": "RUB",             // основная валюта: пороги donationTiers и цели donationSum считаются в ней
  "minAmount": 1,                // донаты меньше — игнорируются
  "donationAlertsClientId": "",  // Client ID приложения DonationAlerts
  "donatePayPollSeconds": 20,    // период опроса DonatePay (минимум 20)
  "callbackPort": 8631,          // порт для входа в DonationAlerts: Redirect URI = http://localhost:ПОРТ/da
  "showMessage": true            // показывать текст донатера в чате Minecraft
},
"donationTiers":        { "1": {...}, "30": {...}, "40": {...}, ... },   // общие эффекты по сумме (51 запись по умолчанию)
"donationAlertsTiers":  {},   // (необязательно) свои эффекты только для DonationAlerts
"donatePayTiers":       {}    // (необязательно) свои эффекты только для DonatePay
```

Плейсхолдеры для донатов: `{sum}` — сумма с символом валюты («500 ₽»), `{amount}` — число, `{currency}` — код валюты,
`{source}` — DonationAlerts / DonatePay, `{message}` — текст донатера, `{session_donations}`, `{session_donation_sum}`,
`{donation_prices_bad}` / `{donation_prices_good}` / `{donation_prices}` — ценник одной строкой (для `reply` чат-команд), `{donation_currency}` — символ валюты.
Цели: тип `donations` (количество донатов) и `donationSum` (сумма в основной валюте) — по умолчанию добавлена цель **Донаты** (каждые 1000 ₽).

## 5г. VK Video Live (live.vkvideo.ru)

Всё, что мод умеет для Twitch, работает и для **VK Video Live** — одновременно с Twitch или вместо него:
чат VK в игре, `!команды` зрителей, **награды за баллы канала** (запросы наград → те же действия, что и
награды Twitch, по названию) и **фолловы** (→ действие `follow`, цели и сборы). Ответы зрителям уходят в чат VK.

Настройка (один раз, 3 минуты) — через экран **VK Video Live** в настройках или командами:

1. Зайди на **https://dev.live.vkvideo.ru/apps** (вход через VK ID) → *Создать приложение*.
   Redirect URI: `http://localhost:8638/vk` (порт можно поменять в настройках — `callbackPort`).
   Скопируй **ID** и **секрет** приложения.
2. В игре: `/twitch vk app <ID> <секрет>` — секрет сохраняется в `config/twitchcraft-vk.json`, не в основной конфиг.
3. `/twitch vk login` → откроется браузер → *Разрешить* → страница «Готово» → мод подключится сам.
   Если браузер не смог открыть localhost — скопируй `code=…` из адресной строки и введи `/twitch vk code <код>`.
4. `/twitch vk rewards sync` — создаст на VK награды из конфига («Пакость», «Подарок»…), которых ещё нет.
   Баллы канала должны быть включены в студии VK Video Live.

Канал берётся из конфига (`vk.channelUrl`, по умолчанию `https://live.vkvideo.ru/dedworkshop`), а если пусто — свой канал
владельца токена. Проверка без зрителей: `/twitch vk test chat <текст>`, `/twitch vk test follow`,
`/twitch vk test reward Пакость`. Статус — `/twitch vk` или `/twitch status`; в оверлее: `VK●` подключено, `VK◌` подключаюсь, `VK○` выключено.

Что настраивается в разделе `vk` конфига: `showChat`, `chatPrefix` (`&9[VK]&r `), `chatCommands`, `rewards`, `follows`,
`replies`, `manageDemands` (подтверждать выполненные запросы наград и **отклонять невыполненные с возвратом баллов**),
`debugEvents` (писать все события VK в лог — пригодится, если VK пришлёт что-то новое: типы событий их WebSocket официально не задокументированы).

Технически: официальный DevAPI (`apidev.live.vkvideo.ru`), OAuth 2.0 Authorization Code с правами
`chat:message:send, channel:points, channel:points:rewards, channel:points:rewards:demands`, WebSocket Centrifugo
(каналы chat / info / channel_points + приватные журнал и награды). Токены продлеваются сами, соединение переподключается,
после обрыва мод забирает пропущенные запросы наград за последние 10 минут.

## 5д. События игры → чат, клипы и метки, таймеры чата

**События игры → чат** (модуль `gameEvents`, экран *События игры → чат*). Мод сам замечает, что произошло в игре, и пишет об этом зрителям в чат Twitch и VK:

| Событие | Сообщение по умолчанию | Переменные |
|---|---|---|
| смерть | `💀 {cause} — смерть №{deaths} за стрим (всего {deaths_total}). F в чат!` | `{cause}` причина как в игре, `{deaths}` за сеанс, `{deaths_total}` за всё время |
| достижение / цель / испытание | `🏆 {player} получил достижение «{advancement}»: {advancement_text}` | `{advancement}`, `{advancement_text}`, `{advancement_kind}` |
| босс повержен (дракон, иссушитель, варден, древний страж) | `⚔ {player} победил босса: {boss}! Боссов за стрим: {bosses}` + заголовок и звук | `{boss}`, `{killer}`, `{bosses}` |
| смена измерения | `🌀 {player} отправился в {dimension}` | `{dimension}`, `{dimension_id}` |

Каждое событие — обычное действие: кроме сообщения в чат можно повесить заголовок, звук и команды. Достижения ловятся **любые** —
ванильные, модовые и из датапаков (мод читает объявление `chat.type.advancement.*`, поэтому в мире должно быть включено правило
`announceAdvancements` — по умолчанию так и есть). Смерть определяется по здоровью игрока, причина берётся из сообщения о смерти.
Счётчик смертей за всё время хранится в `config/twitchcraft-stats.json` (`persistStats`); `{deaths}` и `{session_time}` доступны в любом
действии — например, в чат-командах `!смерти` («Смертей за стрим: 3, за всё время: 41») и `!время` («Стрим идёт 1 ч 20 мин» — время
берётся с Twitch, если стрим в эфире, иначе время сеанса игры). `/twitch game` — счётчики и состояние, `/twitch game test death|advancement|boss|dimension` — проверка, `/twitch game reset [all]` — обнулить.

**Клипы и метки стрима** (модуль `clips`, экран *Клипы и метки*). При смерти, донате от `donationFrom` (50 ₽) и победе над боссом мод ставит
**метку стрима** (точка на таймлайне записи — потом легко найти момент в редакторе Twitch) и делает **клип** (последние ~30 секунд эфира).
Когда Twitch обработает клип (~15 с), ссылка появляется в чате игры (кликабельно, рядом ссылка «обрезать») и уходит зрителям в чаты Twitch/VK
(`clipChatText`, по умолчанию `🎬 Клип: {clip_url}`). Вручную: **F10**, `/twitch clip [повод]`, `/twitch marker [текст]`. Если стрим не идёт,
Twitch отвечает 404 — мод тихо пропускает (раз в 5 минут напомнит в чат игры). Кулдауны: клип 60 с, метка 10 с. Нужны права `clips:edit`
и `channel:manage:broadcast` — после обновления на 1.7.0 сделай `/twitch logout` и `/twitch login` заново, иначе кнопки скажут «нет права».

**Таймеры чата** (модуль `chatTimers`, экран *Таймеры чата*). Сообщение бота раз в N минут, **но только если с прошлого напоминания зрители
написали хотя бы `minChatMessages` сообщений** (чтобы бот не болтал с пустым чатом вне эфира; при тихом чате проверка повторяется каждую минуту).
По умолчанию два таймера: «ценник» (каждые 15 минут, 3+ сообщений: «Донат = событие в игре: ☠ пакости и ★ подарки — !ценник, !плохое, !хорошее…») и выключенный «соцсети» (ссылки на каналы, раз в 30 минут).
В тексте работают `{donation_prices_bad}`, `{donation_prices_good}`, `{deaths}`, `{stream_time}`, `{viewers}`, `{fund_*}` и остальные общие плейсхолдеры.
Команды: `/twitch timers`, `/twitch timers post <имя>` — написать сейчас, `/twitch timers on|off <имя>`.

Раздел конфига: `gameEvents` (действия по ключам `death`, `advancement`, `advancementGoal`, `advancementChallenge`, `boss`, `dimension`),
`gameEventsSettings` (`toTwitch`, `toVk`, `otherPlayers`, `quietSecondsAfterJoin`, `persistStats`), `timers` (список: `name`, `enabled`,
`intervalMinutes`, `minChatMessages`, `text`, `twitch`, `vk`), `clips` (`markerOnDeath`, `clipOnDeath`, `donationFrom`, `markerOnDonation`,
`clipOnDonation`, `markerOnBoss`, `clipOnBoss`, `postClipToTwitch`, `postClipToVk`, `clipChatText`, `clipCooldownSeconds`, `markerCooldownSeconds`).

## 5е. Аддоны TwitchCraft — отдельные мод-файлы (например «Артефакты»)

TwitchCraft 1.8.0 принимает **аддоны**: это отдельные моды (свой jar), которые ставятся в `mods` рядом с TwitchCraft и объявляют
точку входа Fabric `twitchcraft-addon`. Аддон — необязательная часть: без него мод работает как обычно, а `/twitch addons` покажет
«аддоны не подключены». Ошибка аддона не роняет игру: каждый вызов обёрнут в try/catch.

**Аддон «Артефакты»** (`artifact-addon-1.0.0.jar`; механики перенесены с сервера CHRDK REBORN — VKChat Artifacts):

- зрители «выбивают» артефакты за битсы (100), донаты (100 ₽), подписки (1 месяц), подаренные подписки (5), рейды (10 зрителей),
  награды за баллы канала (в названии есть «артефакт»/«artifact») и победы над боссами (50 %);
- 6 редкостей: обычный 40 %, необычный 25 %, редкий 20 %, эпический 10 %, легендарный 4 %, мифический 0,1 %;
  56 баффов (53 обычных + 3 мифических), 13 проклятий, 35 именных артефактов;
- мифические артефакты идут без проклятия и 5-го уровня, часть — особые (Перо Феникса, Корона Бездны, Сердце Дракона);
- проклятие растёт, пока артефакт лежит в инвентаре: **+1 % за 60 минут**; на 100 % артефакт рассыпается навсегда
  (предмет убирается из инвентаря командой; если прав нет — помечается «выгоревшим» и больше не действует);
- не больше **5 артефактов** на игрока: 6-й «ускользает» («Артефактов уже 5 — «…» ускользнул»);
- баффы и проклятия выдаются ванильными эффектами (`/effect give`); баффы без ванильного аналога (вампиризм, молнии и т.п.)
  пока описаны только в лоре — им нужна серверная часть, см. `AUDIT.md`;
- **боссы** (14 штук из серверного аддона: Король Скелетов, Кровавый Палач, Ледяной Скиталец…): раз в 6 часов (настраивается)
  выходит босс в радиусе 5000 блоков от игрока, за 15 минут до появления — объявление с координатами в чаты игры, Twitch и VK,
  при появлении — второй клич и полоса-боссбар. Боссы используют 11 навыков (`MINIONS`, `LIGHTNING`, `EARTHQUAKE`,
  `WITHER_SKULL`, `FIRE_RING`…), срабатывают в 20 % случаев раз в 5 секунд, если зритель (или ты) подошёл ближе 24 блоков;
  за победу — объявление с победителем и 50 % на артефакт. Управление: `/artifact boss` (`list`, `now`, `stop`, `<id>`);
- команды: `/artifact` (и `/артефакт`) — статус; `give [редкость] [ник]`, `held`, `list [редкость]`, `stats`,
  `curse <id> <процент>`, `break <id>`, `reload`;
- файлы: `config/twitchcraft-artifacts.json` (настройки с подсказками и нормализацией значений) и
  `config/twitchcraft-artifacts-state.json` (артефакты и статистика; запись атомарная, повреждённый файл уходит в `.broken`).

Сборка аддона — та же команда, что и у мода: `./gradlew build`. Рядом с модом появится `build/libs/artifact-addon-1.0.0.jar`.
Отдельные модули Gradle не нужны: и мод, и аддон собираются одним `build.gradle` (для Minecraft 26.3 ремап не требуется —
Loom считает такие версии необфусцированными).

**Для разработчиков аддонов.** Интерфейс — `dev.dedworkshop.twitchcraft.api.TwitchCraftAddon` (версия API 1):
`id/title/version`, `onReady(AddonContext)`, `onEvent(TwitchEvent)`, `onTick(Minecraft)`, `onConfigChanged()`, `onShutdown()`.
`AddonContext` даёт папку конфигов (`config/`), потоки TwitchCraft (`scheduler()`, `worker()`), клиент, настройки мода,
чат и объявления в чаты площадок, плейсхолдеры и `runCommand(...)` (в одиночной игре — с правами оператора).

Всё остальное аддон добавляет в мод хуками (как в TikFinity, только на Java — без JSON):

| Хук | Вызов | Что получается |
|---|---|---|
| 1. Переменные | `context.registerVariable("boss_kills", e -> "7")` | плейсхолдер `{boss_kills}` в сообщениях, командах, HUD и оверлее мода |
| 2. Действия (флоу) | `context.registerAction(AddonAction.of("id", "Название", AddonTrigger.cheer(100)).elements(elements))` | мод сам следит за триггером и сам выполняет элементы (сообщение, титул, звук, команды) |
| 3. Награды по id | `context.bindReward("f0a1-…", "Артефакт", (event, input) -> …)` | привязка к конкретной награде за баллы канала по **id**, а не по названию; ввод зрителя приходит аргументом |
| 4. Свои триггеры | `context.registerCustomTrigger(0, "Проверка", "вручную", trigger, actions)` | до **4** кастомных триггеров (`v0…v3`) со своими условиями и действиями |

Триггеры (`AddonTrigger`) — тоже Java: `follow()`, `subscribe()`, `giftSub(5)`, `cheer(100)`, `raid(10)`, `donation(50)`,
`redemption(id)`, `redemptionTitle("Артефакт")`, `chatCommand("артефакт", "artifacts")`, `game(GAME_BOSS)`,
`every()` и `custom(name, params, event -> …)` для своих условий. Элементы (`AddonElements`) собираются по шагам:
`message/title/actionbar/toast/sound/commands/chance/repeat`, поддерживают плейсхолдеры и `blockedCommands`.

Ошибки аддона изолированы: упавшая переменная или условие пишутся в лог, остальные аддоны и мод продолжают работать.
Смотреть, что зарегистрировано: `/twitch addons`, `addons actions`, `addons rewards`, `addons triggers`,
проверить кастомный триггер без зрителей — `/twitch addons fire v0`.

Аддон «Артефакты» — пример использования всех четырёх хуков: 10 переменных (`{artifact_count}`, `{artifact_total}`,
`{artifact_destroyed}`, `{artifact_last}`, `{artifact_limit}`, `{boss_name}`, `{boss_alive}`, `{boss_next}`,
`{boss_defeats}`, `{boss_spawned}`); два действия (справка `!артефакты` и справка `!босс`); привязка наград
из `rewardIds` в своём конфиге (по id) с записью ввода зрителя в чат; все **4 кастомных триггера**: `v0` (проверка
вручную), `v1` (рейд от 25 зрителей), `v2` (босс вышел в мир), `v3` (босс повержен).

Пятый способ отдать моду свою механику — **`context.publish(event)`**: аддон может выпустить игровое событие
в общий конвейер TwitchCraft (действия из `config/twitchcraft.json`, хуки аддонов, журнал). Боссы аддона так и делают:
появление и победа публикуются как события `bossSpawn` и `bossDefeat` — их видно в `/twitch event` и можно настроить
на них свои действия в «События игры» (наравне с «Босс повержен» для ванильных боссов).

### Действие

```json
{
  "message":   "&c{user} &7натравил на тебя зомби!",
  "title":     "&cЗОМБИ!",
  "subtitle":  "&fот {user}",
  "actionbar": "&7Беги!",
  "toast":     "&dНаграда", "toastText": "{reward} от {user}",
  "sound":     "minecraft:entity.zombie.ambient", "volume": 1.0, "pitch": 1.0,
  "commands": [
    "summon minecraft:zombie ~2 ~ ~2",
    "delay 20",
    "summon minecraft:zombie ~-2 ~ ~2"
  ],
  "reply":     "{user}, зомби уже бегут!",
  "chance": 100, "failMessage": "",
  "repeat": "", "repeatPer": 1, "maxRepeat": 10, "repeatDelay": 5,
  "randomOne": false,
  "cooldown": 0, "userCooldown": 0,
  "loot": [
    { "name": "3 печенья",      "weight": 40, "commands": ["give @s minecraft:cookie 3"] },
    { "name": "золотое яблоко", "weight": 20, "commands": ["give @s minecraft:golden_apple 1"] },
    { "name": "алмаз",          "weight": 8,  "commands": ["give @s minecraft:diamond 1"] }
  ],
  "enabled": true
}
```

| Поле | Что делает |
|---|---|
| `message` | Сообщение в чат. Цвета через `&` (`&c` красный, `&a` зелёный, `&d` розовый, `&e` жёлтый, `&l` жирный) |
| `title` / `subtitle` | Большой текст по центру экрана |
| `actionbar` | Текст над хотбаром |
| `toast` / `toastText` | Всплывающее уведомление в правом верхнем углу (как достижение) |
| `sound`, `volume`, `pitch` | Звук, слышный только тебе (id из игры, например `minecraft:ui.toast.challenge_complete`) |
| `commands` | Команды с правами оператора от имени игрока (работает даже с выключенными читами). `/` не нужен. `delay N` — пауза N тиков |
| `randomOne` | Выполнить **одну случайную** команду из списка вместо всех (рулетка) |
| `repeat`, `repeatPer`, `maxRepeat`, `repeatDelay` | Повторы: `"repeat": "{amount}", "repeatPer": 100` — один повтор на каждые 100 битс, не больше `maxRepeat`. В командах доступны `{i}` (номер повтора) и `{repeat}` (всего) |
| `chance`, `failMessage` | Шанс срабатывания в процентах и сообщение при неудаче (лотерея) |
| `cooldown`, `userCooldown` | Кулдаун в секундах: общий и на одного зрителя. На кулдауне награда **возвращает баллы** (если создана модом) и отвечает в чат |
| `reply` | Ответ в чат Twitch от твоего имени |
| `permission`, `aliases` | Только для чат-команд: `everyone`, `subscriber`, `vip`, `moderator`, `broadcaster`; другие имена команды |
| `cost`, `prompt`, `input`, `color` | Только для наград: параметры для `/twitch rewards sync` (цена, описание, требовать ввод текста, цвет `#RRGGBB`) |
| `loot` | **Таблица лута**: список записей `{ "name", "weight", ...любые поля действия... }`. При срабатывании выпадает **одна** запись (шанс = `weight` / сумма весов), её `name` доступен как `{loot}` уже в `message`/`title` основного действия, а её команды и эффекты выполняются после основных. Запись с `enabled: false` или `weight: 0` не выпадает |
| `name`, `weight` | Только для записей лута: название (→ `{loot}`) и вес |
| `enabled` | `false` — временно выключить действие, не удаляя |

Любое поле можно опустить. Пустое действие `{}` = ничего не делать.

### Плейсхолдеры

| Плейсхолдер | Значение |
|---|---|
| `{user}` / `{user_login}` | имя / логин зрителя |
| `{amount}` | битсы / месяцы подписки / количество подарков / зрители рейда / стоимость награды / сумма доната (число) |
| `{sum}`, `{currency}`, `{source}` | донаты: сумма с символом валюты («500 ₽»), код валюты, сервис (DonationAlerts / DonatePay) |
| `{message}` | текст зрителя (к битсам, ресабу, ввод к награде, аргументы чат-команды) |
| `{reward}` | название награды |
| `{tier}` | уровень подписки: 1, 2, 3 или Prime |
| `{command}` | имя чат-команды |
| `{player}` | твой ник в Minecraft |
| `{i}`, `{repeat}` | номер текущего повтора и общее число повторов |
| `{loot}` | название выпавшей записи таблицы лута (пусто, если таблицы нет) |
| `{goal}`, `{target}`, `{times}` | в действии цели или сбора: название, порог (цель сбора) и сколько раз достигнута / закрыт (`{user}` — кто внёс последний вклад; `{sum}` — цель сбора с валютой) |
| `{fund}` `{fund_current}` `{fund_target}` `{fund_left}` `{fund_percent}` `{fund_currency}` `{fund_donors}` | в любом действии: состояние главного сбора средств (для `!сбор`) |
| `{donation_prices_bad}` `{donation_prices_good}` `{donation_prices}` `{donation_currency}` | в любом действии: ценник донатов одной строкой («30 Тыква · 50 Голод · …») и символ валюты (для `!плохое` / `!хорошее`) |
| `{session_follows}` `{session_subs}` `{session_gifts}` `{session_bits}` `{session_raids}` `{session_rewards}` `{session_donations}` `{session_donation_sum}` `{session_events}` `{session_minutes}` | статистика текущей сессии (удобно для `reply` в команде `!stats`) |
| `{deaths}` `{deaths_total}` `{advancements}` `{advancements_total}` `{bosses}` `{bosses_total}` `{last_death}` `{session_time}` | в любом действии: счётчики событий игры за сеанс / за всё время, последняя смерть, время в игре («1 ч 05 мин») |
| `{stream_time}` `{viewers}` `{live}` `{stream_title}` `{stream_game}` | в любом действии: состояние стрима Twitch (обновляется раз в минуту) — «1 ч 20 мин» / «не в эфире», зрители |
| `{cause}` `{advancement}` `{advancement_text}` `{advancement_kind}` `{boss}` `{killer}` `{dimension}` `{dimension_id}` | только в действиях событий игры (раздел 5д) |
| `{clip_url}` `{why}` | в тексте сообщения о клипе (`clips.clipChatText`) |

Текст зрителей автоматически очищается от кавычек, переводов строк и цветовых кодов, а плейсхолдеры
подставляются за один проход — зритель не сможет «вставить» свой плейсхолдер в команду.

### Награды за баллы канала

Два способа:

1. **Автоматически:** `/twitch rewards sync` — мод создаст на Twitch все награды из `rewards`, которых ещё нет
   (цена из `cost`, описание из `prompt`, кулдаун из `cooldown`). Такие награды мод может **подтверждать**
   (`autoFulfill`) и **отменять с возвратом баллов** (`autoRefund`) — например, если ты был в меню, очередь переполнена
   или награда на кулдауне.
2. **Вручную:** создай награды в панели Twitch (*Монетизация → Баллы канала → Управление наградами*)
   с такими же названиями, как ключи в `rewards` (регистр не важен). Twitch не разрешает моду менять статус
   «чужих» наград, поэтому возврат баллов для них работать не будет.

В конфиге по умолчанию **две награды по 250 баллов** и запасной `*`:

| Награда | Что делает |
|---|---|
| `Пакость` | **случайное ☠ событие** из ценника донатов (одно из 25: тыква на голову, зомби, крипер, молния, Иссушитель…) |
| `Подарок` | **случайное ★ событие** из ценника (одно из 25: перекус, алмазы, тотем, незерит, Легенда…) |

За это отвечает поле действия `"pool": "bad"` / `"good"` / `"any"`: мод равновероятно выбирает запись ценника
с нужным знаком и выполняет её команды, звук и заголовок, а в сообщении награды доступны `{picked}` (название),
`{picked_text}` (описание) и `{picked_full}` (со значком). Выключенные записи ценника в розыгрыше не участвуют;
если убрать из ценника все ☠, награда выполнит только своё действие и предупредит в чате.
Названия на Twitch / VK должны совпадать с ключами (`/twitch rewards sync` и `/twitch vk rewards sync` создадут их сами).
Хочешь свои награды с фиксированным эффектом — добавь их рядом (без `pool`), как в версиях до 1.6.

### Подарки за фоллов, подписку и рейд

По умолчанию каждое событие даёт **ощутимый** подарок в инвентарь (всё правится в *События Twitch* или в конфиге):

| Событие | Всегда | Таблица лута (одна случайная запись) |
|---|---|---|
| Фоллов | частицы-сердечки, звук, тост | 3 печенья (40) · золотое яблоко (20) · 2 железных слитка (20) · изумруд (10) · алмаз (8) · ЗАЧАРОВАННОЕ яблоко (2) |
| Подписка | алмаз, заголовок, звук, ответ в чат | 3 золотых яблока (30) · 5 изумрудов (30) · 20 уровней опыта (25) · ТОТЕМ (10) · незеритовый слиток (5) |
| Рейд | скорость + сопротивление, золотой слиток за каждые 5 зрителей | 5 золотых слитков (40) · 8 золотых морковок (25) · 16 пузырьков опыта (20) · алмазный меч (10) · ЭЛИТРЫ (5) |

В скобках — вес: шанс = вес / сумма весов. Таблицу лута можно добавить **любому** действию: награде за баллы,
чат-команде, порогу битсов, цели. Название выпавшей записи подставляется как `{loot}`
(например, `"message": "&d{user} &7зафолловил! Подарок: &6{loot}"`).

### Цели

Цель — счётчик «каждые N … → награда». Прогресс хранится в `config/twitchcraft-goals.json`, переживает перезапуск игры
и показывается в оверлее (F7) и по `/twitch goals`. Если мод не запускался дольше `goalsSettings.resetAfterHours`
(по умолчанию 12 ч), счётчики обнуляются — новый стрим начинается с нуля.

```json
{ "name": "Фолловеры", "type": "follows", "target": 10, "repeat": true, "enabled": true,
  "action": { "message": "&6ЦЕЛЬ: {target} новых фолловеров! &7Спасибо, {user}!", "title": "&6ЦЕЛЬ ДОСТИГНУТА",
              "sound": "minecraft:ui.toast.challenge_complete", "commands": ["give @s minecraft:diamond 3"] } }
```

| Поле | Значение |
|---|---|
| `type` | что считаем: `follows`, `subs` (новые + продления + подарки), `gifts`, `bits`, `raids`, `raidViewers` (сумма зрителей рейдов), `rewards` (активации), `points` (потраченные баллы), `donations` (количество донатов), `donationSum` (сумма донатов в валюте `donations.currency`), `events` (любые события) |
| `target` | сколько набрать |
| `repeat` | `true` — после достижения цель начинается заново (каждые N); `false` — один раз |
| `action` | обычное действие (с таблицей лута, повторами и т.д.); плейсхолдеры `{goal}`, `{target}`, `{times}`, `{user}` |

По умолчанию: **Фолловеры** (каждые 10), **Подписки** (каждые 5), **Битсы** (каждые 1000), **Рейдеры** (каждые 100 зрителей из рейдов суммарно), **Донаты** (каждые 1000 ₽).
Одно событие двигает цель не больше чем на **5 срабатываний** подряд (рейд на 1000 зрителей при цели «каждые 10» не устроит
100 наград разом): остаток остаётся в прогрессе и «догоняется» следующими событиями.
Команды: `/twitch goals` — прогресс, `/twitch goals reset [цель]` — сброс, `/twitch goals add <цель> <n>` — подвинуть счётчик вручную,
`/twitch test goal <цель>` — выполнить награду цели.

### Сборы средств — полоса-боссбар

Сбор — «копилка с целью», которая висит вверху экрана **как полоса здоровья босса** (те же спрайты, ширина и отступ, что
у дракона и визера): `Сбор на стрим: 3 500 / 10 000 ₽ (35%)`, справа 8 секунд после вклада — `+500 ₽ · Ник`. В отличие от целей
сбор **не сбрасывается сам** и показывается постоянно, пока не спрячешь. Прогресс — в `config/twitchcraft-fundraisers.json`.

```json
{ "name": "Сбор", "title": "&6Сбор на микрофон", "target": 10000, "color": "pink", "style": "notched_10",
  "countDonations": true, "bitsRate": 0.7, "subValue": 150, "pointsRate": 0, "hideWhenCompleteSeconds": 0,
  "visible": true, "enabled": true, "format": "{title}: {current} / {target} {currency} ({percent}%)",
  "action": { "title": "&6СБОР ЗАКРЫТ!", "subtitle": "&f{sum} — спасибо всем!", "sound": "minecraft:ui.toast.challenge_complete" } }
```

| Поле | Значение |
|---|---|
| `target` | цель в основной валюте (`donations.currency`, по умолчанию RUB) |
| `countDonations`, `bitsRate`, `subValue`, `pointsRate` | что засчитывать: донаты как есть; «курс» за 1 битс, за подписку, за 1 балл канала (0 — не считать) |
| `color` / `style` | `pink blue red green yellow purple white` / `progress notched_6 notched_10 notched_12 notched_20` |
| `visible` / `hideWhenCompleteSeconds` | спрятать полосу (вклады считаются) / спрятать через N с после закрытия |
| `action` | эффект при достижении цели: `{goal}`, `{target}`, `{sum}`, `{times}`, `{user}` |

Общие настройки `fundraiserSettings`: `y` — отступ сверху (12; если на экране босс — 31+), `lastContributionSeconds`, `animate`.
Команды: `/twitch fund` — список, `fund create <имя> <цель> [заголовок]`, `fund add <имя> <сумма> [от кого]` (деньги мимо сервисов,
может закрыть сбор), `fund set`, `fund target`, `fund title`, `fund show|hide`, `fund reset [имя]`, `fund remove`, `/twitch test fund <имя>`.
Чат-команда `!fund` / `!сбор` отвечает зрителям текущим состоянием. Тестовые события и F9 в сбор не засчитываются.
Полосу видишь ты и захват игры (OBS); она прячется вместе с интерфейсом (F1).

### Чат Twitch и чат-команды

- При включённом модуле `twitchChat` сообщения чата показываются в игре как `[T] ⚔ Ник: текст`
  (♛ стример, ⚔ модератор, ◆ VIP, ★ подписчик; ник — в цвете зрителя). Быстро выключить: `/twitch chat off`.
- Команды из `chatCommands` зрители пишут в чат Twitch: `!zombie`. Проверяются права (`permission`), кулдауны,
  список `ignoredUsers`. `hideCommands: true` — команды не показываются в чате игры, а только выполняются.
- По умолчанию есть `!zombie`, `!heal`, `!stats`, `!fund` (`!сбор`) и ценник донатов: `!ценник` (`!prices`, `!донат`, `!цены`) — как это
  работает, `!плохое` (`!bad`, `!пакости`) и `!хорошее` (`!good`, `!подарки`) — списки событий с ценами (нужен scope `user:write:chat`).
- **Общий чат (Shared Chat)**: когда ты стримишь в общем чате с другим каналом, сообщения, написанные в чате партнёра,
  показываются с пометкой `[канал]` (`twitchChat.showSharedChat`), но **не запускают твои чат-команды** — зрители чужого
  канала не могут спавнить тебе мобов. Разрешить: `twitchChat.sharedChatCommands: true` (или тумблер «Общий чат: команды»
  в настройках).
- `reply` в любом действии и `/twitch say <текст>` пишут в чат Twitch от твоего имени (лимит Twitch — 20 сообщений за 30 с,
  мод сам выдерживает паузы).

## 8. Сборка из исходников

Нужен **JDK 25** (<https://adoptium.net/temurin/releases/?version=25>). Затем в папке проекта:

```bash
# Windows
gradlew.bat build
# macOS / Linux
./gradlew build
```

Готовый мод появится в `build/libs/twitchcraft-1.8.0.jar` (и `artifact-addon-1.0.0.jar`, если собран аддон «Артефакты»).
Первая сборка качает Minecraft и зависимости (~600 МБ) — это нормально.

**IntelliJ IDEA** (Community бесплатна): *File → Open* → папка проекта → дождаться синхронизации Gradle.
В списке конфигураций запуска появится **Minecraft Client** — можно запускать игру с модом прямо из IDE.

Поток данных: **Twitch → EventSubClient / VK Video Live → VkPubSub (сетевые потоки) → TwitchEvent (с полем `platform`) →
основной поток игры → EventProcessor (очередь/кулдауны) → ActionRunner → команды на встроенном сервере.**
События самой игры идут тем же путём: **GameEvents → TwitchEvent типа GAME → EventProcessor (без очереди и лимитов) → ActionRunner →
`reply` в чаты Twitch и VK** (+ ClipManager для клипов и меток).

Что изменилось в Fabric начиная с 26.1 (если будешь читать старые туториалы):
- Minecraft больше не обфусцирован — маппинги (Yarn/Mojmap) не нужны, плагин называется `net.fabricmc.fabric-loom`
- Вместо `modImplementation` пишут просто `implementation`
- Нужна Java 25; `ResourceLocation` переименован в `Identifier`; клиентские команды — класс `ClientCommands`;
  клавиши — `KeyMappingHelper`, HUD — `HudElementRegistry`

В папке `dev-tests/` лежат автотесты (`run_tests.sh`): 345 проверок логики (разбор событий, конфиг и миграция,
плейсхолдеры, кулдауны, повторы, модули, таблицы лута, цели, очередь выполнения действий, разбор донатов, курсор DonatePay, callback-сервер,
случайные награды «Пакость»/«Подарок», разбор событий VK, счётчики событий игры, разбор достижений и причин смерти, таймеры чата на фальшивых часах,
решения о клипах/метках), 34 интеграционные проверки против «фейкового Twitch» (`mock_twitch.py`): подписки, чат,
переподключение, watchdog, подтверждение/возврат наград, состояние стрима, метки и клипы (включая 404 вне эфира и ожидание готовности клипа), 58 проверок против «фейковых DonationAlerts и DonatePay» (`mock_donations.py`): OAuth URL/invalid_client, вход через браузер,
Centrifugo, дедупликация, переподключение, отзыв токена, проверка ключа, посев курсора, ожидание платежей, модули, и 36 проверок против «фейкового VK Video Live»
(`mock_vk.py`): вход по коду через localhost, канал и токены WebSocket, события чата / наград / фолловов с дедупликацией, подтверждение и отклонение запросов,
отправка в чат с повтором, продление токенов (WebSocket и 401 → refresh), обрыв соединения с догонкой запросов, создание наград, выход.

Mod Menu подключён как `compileOnly`-зависимость: мод компилируется с его API, но в игре работает и без него —
класс `ModMenuIntegration` загружается только когда Mod Menu установлен (точка входа `modmenu` в `fabric.mod.json`).

## 10. Если что-то не работает

| Симптом | Что проверить |
|---|---|
| `Twitch ответил 400/403` при `/twitch login` | Client ID скопирован целиком; тип клиента приложения — **Public** |
| `подписок: 0/8` | Ты вошёл не под аккаунтом владельца канала. `/twitch logout` → `/twitch login` под dedworkshop |
| `подписок: 4/8` или около того | Подписки на баллы/битсы/сабы создаются только у **аффилиатов/партнёров**. Фолловы, рейды и чат работают у всех |
| Чат не показывается / `reply` не работает / `rewards sync` ругается на права | Токен выдан старой версией. `/twitch logout` → `/twitch login` и подтверди новые права. Проверить: `/twitch status` (строка «Доп. права») |
| Награда не срабатывает | Название в `rewards` должно совпадать с наградой на Twitch. `/twitch rewards`, `/twitch test reward <название>`, `/twitch history` |
| Баллы не возвращаются | Возврат работает только для наград, созданных модом (`/twitch rewards sync`). Чужие награды Twitch менять не даёт (403) |
| События не выполняются, в чате «В очередь (пауза)» | Нажми F8 или `/twitch resume`. `/twitch queue` покажет очередь |
| Команды не выполняются на сервере | На чужом сервере команды уходят от твоего имени — нужен OP. В одиночке работает всегда |
| `Команда /xxx заблокирована` | Команда есть в `blockedCommands` — это защита; убери из списка, если уверен. Проверяется и команда после `run` внутри `execute … run …` |
| В логе «Ошибка чтения конфига … (копия файла: twitchcraft.json.broken-…)» | В JSON опечатка (мод подскажет строку). Твои правки лежат в копии `.broken-<дата>` рядом — исправь и верни содержимое в `twitchcraft.json`, потом `/twitch reload` |
| `Связь с Twitch потеряна` | Мод переподключится сам (1, 2, 4… до 60 с). Если постоянно — проверь VPN/фаервол (нужны `eventsub.wss.twitch.tv`, `api.twitch.tv`, `id.twitch.tv`; для донатов — `www.donationalerts.com`, `centrifugo.donationalerts.com`, `donatepay.ru`) |
| В Mod Menu нет кнопки «Настроить» | Проверь, что стоит Mod Menu **21.x для 26.3**. Без Mod Menu используй `/twitch config` |
| Цели не растут | Модуль `goals` включён? (`/twitch modules`). Тестовые события и повторы F9 в цели не засчитываются — проверяй через `/twitch goals add <цель> 1` |
| Подарок не выдаётся | В таблице лута все записи выключены или с весом 0; смотри `/twitch history` и `showCommandOutput: true` для ответа команды `give` |
| DonationAlerts: «Не указан Client ID» | `/twitch donations da client <ID>` — числовой ID приложения с donationalerts.com/application/clients, не Client Secret |
| DonationAlerts: `invalid_client` / `Client authentication failed` сразу в браузере | Проверь числовой Client ID и точный Redirect URI из экрана «Донаты» (`http://localhost:<callbackPort>/da`; по умолчанию `http://localhost:8631/da`). Секрет для используемого implicit OAuth не нужен. Если значения верны, проверь, что приложение не удалено/не отключено в DonationAlerts |
| DonationAlerts: браузер пишет «redirect_uri не совпадает» | В приложении DonationAlerts Redirect URI должен быть ровно `http://localhost:<порт>/da` (порт — как в `donations.callbackPort`) |
| DonationAlerts: «Не удалось открыть локальный порт» | Порт 8631 занят другой программой — смени `donations.callbackPort` (и Redirect URI в приложении) |
| DonationAlerts: «токен недействителен» | `/twitch donations da login` ещё раз (токен отозван или приложение удалено) |
| DonatePay: «не принял ключ» | Ключ скопирован не целиком или перевыпущен: donatepay.ru → Настройки → API → `/twitch donations dp key <ключ>` |
| DonatePay: «слишком частые запросы» | Лимит DonatePay — 1 запрос в 20 с на ключ. Закрой другие программы, использующие тот же ключ (или подожди минуту) |
| Донат пришёл, но эффекта нет | Сумма меньше `minAmount`? Модуль включён (`/twitch modules`)? Смотри `/twitch history` и `/twitch donations` |
| Хочу начать заново | Удали `config/twitchcraft-tokens.json` (или `/twitch logout`), `config/twitchcraft-donations.json` (или `da logout` / `dp logout`) и при желании `config/twitchcraft.json`, `config/twitchcraft-goals.json`, `config/twitchcraft-fundraisers.json` |

Подробные логи: `.minecraft/logs/latest.log` (строки `TwitchCraft` и `EventSub`) и `.minecraft/logs/twitchcraft-events.log`.

## 11. Безопасность

- Файлы `config/twitchcraft-tokens.json` (Twitch) и `config/twitchcraft-donations.json` (токен DonationAlerts, API-ключ DonatePay)
  дают доступ к событиям твоего канала — **не показывай их на стриме** и никому не отправляй. Client ID секретом не является.
- Для входа в DonationAlerts мод на 10 минут открывает порт `8631` **только на localhost** (127.0.0.1) и закрывает его сразу после получения токена.
- Мод может писать в чат от твоего имени (только то, что ты сам указал в `reply` / `/twitch say`) и управлять
  наградами за баллы. Банить, менять настройки канала или стрима он не может — таких прав не запрашивается.
- Опасные команды (`stop`, `op`, `ban`, `kick`, `whitelist`…) заблокированы списком `blockedCommands` — в том числе
  спрятанные в цепочки `execute … run <команда>` / `return run <команда>`; текст зрителей очищается, плейсхолдеры не раскрываются рекурсивно.
- Файлы настроек и токенов записываются атомарно (временный файл → замена), так что вылет игры посреди сохранения их не испортит;
  если файл всё же повреждён, мод откладывает копию `*.broken-<дата>` и не затирает твои правки.
- Отозвать доступ можно в любой момент: <https://www.twitch.tv/settings/connections> → *Другие подключения*.
